# 🌲 AkhriPasta - Survival Game

A text-based wilderness survival game built in Python.

## 🎮 About
Survive as long as possible in the wilderness!
Manage your health, hunger, thirst and energy
while building shelter, making fire and hunting food.

## 🕹️ How to Play
```bash
python survival_game.py
```

## ⚙️ Features
- 5 unique locations to explore
- Dynamic weather system
- Shelter and fire building
- Hunting and gathering
- Random events
- Score system

## 📦 Requirements
- Python 3.x
- No extra libraries needed!

## 🚀 Getting Started
1. Clone the repo
2. Run `python survival_game.py`
3. Try to survive!
